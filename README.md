# Ball Race (clone)

A hyper-casual ball race clone made with Unity.

## About
The player's ball races against AI opponents to the end point. Opponents move with Unity NavMesh.

## What's inside
- Ball movement (`BallMovement`) and player handling (`PlayerManager`)
- Opponents driven by NavMesh (`OpponentManager`)
- Finish handling (`EndPointManager`) and camera follow (`CameraManager`)
- `EventManager` (Observer / event-driven communication)

## Tech
- Unity 2020.3.25f1
- C#
- NavMesh, Observer pattern

## Run it
Open the project folder with Unity **2020.3.25f1** (Unity Hub → *Add project from disk*), then open the main scene in `Assets/Scenes` and press Play.
